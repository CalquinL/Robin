# Robin
https://robin-github-io.vercel.app/index.html

Robin es una plataforma web que conecta a personas que atraviesan necesidades puntuales —la llegada de un bebé, una emergencia, una fecha especial— con donantes dispuestos a ayudar mediante la entrega directa de bienes, evitando el manejo de dinero y la complejidad legal y tributaria que eso implica.
 
A diferencia de las plataformas de donación existentes en Chile, orientadas principalmente a organizaciones registradas, Robin está pensada para personas individuales que necesitan ayuda concreta y verificable.
